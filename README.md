# XCASH HT — App Investisman

Aplikasyon mobil **XCASH HT** (Haiti), kreye ak Flutter.

## Deskripsyon

App envestisman pou mache ayisyen an. Itilizatè yo fè depo atravè MonCash/NatCash, achte plan envestisman, epi resevwa peman otomatik apre 1h45 minit.

- **Backend**: Supabase Edge Function `xcash`
- **Pake Android**: `com.xcashht.app`
- **Vèsyon**: 1.0.7+7

## Estrikti

- `lib/` — Kòd Dart (UI, screens, API)
- `android/` — Pwojè Android
- `ios/` — Pwojè iOS
- `assets/logo.png` — Logo app
- `.github/workflows/ios-build.yml` — Build IPA sou GitHub Actions

## Build iOS (unsigned IPA)

Repo sa a genyen yon GitHub Actions workflow ki bati yon `.ipa` san siyati sou macOS. Gade `GID-IOS-MEN-KREYOL.md` pou gid konplè.
